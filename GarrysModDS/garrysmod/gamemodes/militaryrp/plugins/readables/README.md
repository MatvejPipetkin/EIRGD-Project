# Плагин «Литература и обучение» (Helix)

Книги, газеты, журналы и документы, которые прокачивают атрибуты. Плюс три новых атрибута с пассивными бонусами.

## Установка
Скопируйте папку `readables` в `schema/plugins/` (или `plugins/`) и перезапустите сервер.
Нужны атрибуты `survival`, `athletics`, `medical` из вашей схемы: предметы выдают им опыт, а если какого-то атрибута нет, он просто пропускается.

## Как работает чтение
- Предмет → **Читать**: полоса действия, по окончании выдаётся опыт и открывается окно с текстом.
- Предмет → **Просмотреть**: открыть текст без опыта и без ожидания.
- Опыт за **первое** прочтение полный, за повторное только `rereadFactor` (25%).
- После прочтения у предмета откат (`ITEM.cooldown`), в течение которого читать за опытом нельзя.
- Чтение прерывается, если игрок получил урон.
- Записи о прочитанном хранятся в данных персонажа (`readLog`).

## Сколько опыта даёт каждый тип (до множителей)
| Тип | Опыт | Время | Откат |
|---|---|---|---|
| Газета | 0.1 | 5 с | 10 мин |
| Журнал | 0.3 | 10 с | 20 мин |
| Документ | 0.5 | 12 с | 30 мин |
| Книга | 1.5 | 20 с | 1 ч |
| Учебник | 2–3 | 30 с | 2 ч, нужны навыки |

Газеты дают меньше всего. Общий множитель регулируется конфигом `readXPScale`.

## Новые атрибуты
| Атрибут | Бонусы на максимуме |
|---|---|
| Ловкость (`agility`) | скорость ходьбы и бега +12%, прыжок +15%, урон от падения −50% |
| Скрытность (`stealth`) | скорость в приседе +35%, с 50% атрибута бесшумные шаги в приседе и при ходьбе на ALT |
| Эрудиция (`erudition`) | чтение быстрее на 40%, опыт за чтение +30%, открывает сложные учебники |

Числа лежат в `ix.readables.perks` (`sh_plugin.lua`). Если измените их, поправьте описания в `attributes/`.

## Конфиг (вкладка «Чтение»)
- `readXPScale`: множитель опыта.
- `readTimeScale`: множитель времени чтения.
- `rereadFactor`: доля опыта при повторном чтении.

## Как добавить свой предмет
Создайте `items/sh_my_book.lua`:

```lua
ITEM.name = "Книга «Название»"
ITEM.description = "Описание."
ITEM.base = "base_readable"
ITEM.model = "models/props_lab/binderblue.mdl"
ITEM.readTime = 20
ITEM.cooldown = 3600
ITEM.attributes = {survival = 1.5, erudition = 0.2}
ITEM.requirements = {erudition = 5} -- необязательно
ITEM.content = [[Текст, который увидит игрок.]] -- необязательно
```

## API для других плагинов
- `ix.readables.GetSpeedMultiplier(target, bCrouching)`, `GetJumpMultiplier`, `GetFallDamageMultiplier`
- `ix.readables.GetReadTimeMultiplier`, `GetXPMultiplier`
- `ix.readables.StartReading(client, item)`, `ix.readables.OpenContent(client, item)`
- Хук `PlayerReadMaterial(client, item, scale)` вызывается после каждого прочтения.

## Заметки
- Модели предметов стандартные из HL2 (папки-«биндеры», газета, листок). Замените на свои при необходимости.
- Функции `ix.military.*` из ваших `sh_survival/athletics/medical.lua` этот плагин не вызывает: они остаются как есть.

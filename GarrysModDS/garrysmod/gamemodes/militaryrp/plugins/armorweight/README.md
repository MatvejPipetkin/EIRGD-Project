# Armor & Weight — плагин для Helix

Вес и характеристики брони: чем тяжелее снаряжение, тем медленнее ходьба и бег.
Броня изнашивается от попаданий и требует починки (плагин `plugin_pochinka`).

## Установка

Скопируйте папку `armorweight` в `gamemodes/<ваша_схема>/plugins/` и перезапустите сервер.

```
plugins/armorweight/
  sh_plugin.lua
  items/base/sh_armorweight.lua   -- база: base_armorweight (внутри шаблон настроек)
  items/sh_aw_*.lua               -- примеры предметов
```

## Как задать предмет

Все характеристики — одним блоком `ITEM.armorStats`. Ненужную строку можно не писать.

```lua
ITEM.name = "Тяжёлый бронежилет"
ITEM.description = "Плитоносец с керамическими пластинами."
ITEM.model = "models/props_c17/BriefCase001a.mdl"
ITEM.width = 3
ITEM.height = 3
ITEM.base = "base_armorweight"

ITEM.armorStats = {
	slot = "body",         -- слот: в одном слоте носится один предмет
	weight = 11,           -- вес, кг
	protection = 60,       -- бронирование, %
	blast = 20,            -- взрывоустойчивость, %
	ergonomics = -8,       -- эргономика, % к скорости (минус — замедляет)
	coverage = {"torso"},  -- зоны: head, chest, stomach, torso, arms, legs, all
	durability = 150,      -- макс. прочность; не писать — общая; false — не изнашивается
}
```

| Параметр | Что делает |
|---|---|
| `slot` | Слот (`body`, `head`, ...). По умолчанию `body` |
| `weight` | Вес, кг. Суммируется по всем надетым предметам |
| `protection` | Доля урона (пули, дробь, ножи, дубинки), которая игнорируется, % |
| `blast` | Доля урона от взрывов, которая игнорируется, % |
| `ergonomics` | % к скорости. Отрицательное значение замедляет |
| `coverage` | Закрываемые зоны. Можно строкой: `coverage = "torso"` |
| `durability` | Максимальная прочность. `false` — предмет не изнашивается |

Опечатки в названиях параметров и зон выводятся в консоль сервера при старте:
`[armorweight] sh_aw_vest: неизвестный параметр armorStats.wieght`.

Старые плоские поля (`ITEM.armorWeight`, `armorPercent`, `blastResist`, `ergonomics`, `coverage`,
`armorSlot`, `maxDurability`) продолжают работать: если параметра нет в `armorStats`, берётся оно.

## Цвета в подсказке предмета

Каждая характеристика — отдельная строка своего цвета: красный → жёлтый → зелёный.

- **Вес:** чем легче, тем зеленее (30 кг и больше — красный).
- **Бронирование и взрывоустойчивость:** чем выше, тем зеленее (80% и больше — зелёный, 0 — серый).
- **Эргономика:** 0 — зелёный, −15% и ниже — красный.
- **Покрытие:** голубой. **Состояние:** по доле прочности.

Цвета и шкалы меняются в `sh_plugin.lua`: таблицы `gear.colors` и `gear.statScale`.
Названия состояний — `gear.conditionNames`.

## Износ и состояние

- Каждый надетый предмет, который принял удар, теряет прочность:
  `урон × бронирование предмета × armorWearRate`. Взрыв изнашивает по взрывоустойчивости.
- Изнашивается только тот предмет, который закрывает зону попадания.
- **Защита пропорциональна состоянию:** при 50% прочности предмет даёт половину защиты,
  сломанный (0) не защищает совсем, но вес и эргономика остаются.
- Состояние видно в подсказке (`Состояние: 73% (Хорошее)`; защита показывается как `30% (из 60%)`)
  и цветной полоской внизу иконки.
- Починка — плагин `plugin_pochinka` (ремкомплекты для брони `sh_armor_kit_*`).
- Прочность хранится в данных предмета (`durability`) под тем же ключом, что и у оружия.

## Как считается

- **Скорость** = `100% + сумма эргономики − (вес − свободный вес) × штраф за кг`, не ниже минимума.
- **От `armorNoSprintWeight` кг** бег отключается, остаётся только ходьба.
- **Защита по зонам:** броня работает, только если зона попадания закрыта предметом (`coverage`).
- **Несколько слоёв** в одной зоне складываются с убывающей отдачей: 30% и 60% дают 72%, а не 90%.
- **Потолок** защиты — `armorMaxReduction` (по умолчанию 90%).
- **Взрывы** (`DMG_BLAST`) режутся только взрывоустойчивостью, остальной урон (падение, огонь, яд, радиация) броня не трогает.

## Настройки

В меню конфигурации Helix, категория «Броня и вес»:

| Ключ | По умолчанию |
|---|---|
| `armorFreeWeight` | 6 кг |
| `armorSlowPerKg` | 1.2 % за кг |
| `armorMinSpeed` | 40 % |
| `armorNoSprintWeight` | 40 кг (0 — не отключать бег) |
| `armorMaxReduction` | 90 % |
| `armorWearRate` | 0.15 (0 — броня не изнашивается) |

Общая максимальная прочность — `maxValueDurability` из плагина починки (по умолчанию 100).

Пример износа: пуля 50 урона в жилет с защитой 60% съедает `50 × 0.6 × 0.15 = 4.5` прочности.

## Команда

`/ArmorStats` — показывает вес, скорость и защиту вашей экипировки.

## Совместимость с Simple Inventory Slots

Плагин считает надетые предметы во всех инвентарях персонажа, включая слоты экипировки, и пересчитывает характеристики при перекладывании предмета в слот и обратно.

Для одежды из слотов базу `base_armorweight` указывать не нужно: файл кладётся в `simpleinvslots/items/slot_clothing/` и в него просто добавляется блок `ITEM.armorStats` (слот там задаёт `ITEM.slot`). Готовые примеры лежат в `simpleinvslots_examples/`. Характеристики, состояние и полоска на иконке работают и для такой одежды, а чинится она теми же ремкомплектами.

`ITEM.maxArmor` у таких предметов лучше не задавать (или поставить 0): иначе будет действовать ещё и стандартная броня Garry's Mod, и защита посчитается дважды.

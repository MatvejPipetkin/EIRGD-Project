# Плагин «Хакерский терминал» для Helix

Особый предмет `hacktool` («Хакерский терминал») для спецклассов. Игрок подходит к серверному узлу на карте,
проходит хакерские мини-игры и получает эффект против вражеской фракции. Откат — 15 минут на персонажа.

## Установка
1. Папку `hacking` положить в `schema/plugins/` (рядом с плагинами `tablet` и `radioimba`). Правок в их файлах не нужно:
   плагин сам «подхватывает» планшет и рацию при загрузке.
2. Перезапустить сервер.
3. Расставить узлы (команды ниже), выдать предмет: `/CharGiveItem <ник> hacktool`.

## Кто может пользоваться
Классы (настраивается в `sh_plugin.lua` → `HACK.classes`): `fvur_scout`, `eir_engineer`, `eir_signaller`, `eir_spec`.
Жертва — вражеская фракция (`HACK.factions`: fvur <-> eir_republic). Если у узла задан владелец, жертва — он.

## Как играть
- Подойти к узлу (≤140 ед.), навести прицел и нажать **E** либо использовать предмет → «Подключиться к узлу».
- Предмет → «Сканировать сеть»: метки ближайших узлов на экране 20 с.
- Предмет → «Открыть досье»: последние полученные данные архива.
- Откат 15 мин стартует в момент начала взлома (прервать и начать заново нельзя). Узел после взлома восстанавливается
  20 мин (после провала 5 мин). Если отойти дальше ~260 ед., умереть или сменить персонажа — сеанс обрывается.
- Провал → фракция-жертва получает сообщение-тревогу.

## Мини-игры (задание генерирует и проверяет СЕРВЕР)
На узел даётся 5 «жизней»: жизнь теряется, если вышло время или игра провалена. Игры подбираются по этапам без повторов.

| Игра | Суть |
|---|---|
| Подбор пароля | В дампе памяти спрятаны слова-кандидаты. Выбираете слово, узел говорит, сколько букв стоит на своём месте, и по этим подсказкам нужно вычислить пароль за ограниченное число попыток. |
| Дешифровка | Сообщение зашифровано сдвигом по алфавиту. Шифр-диск выставляется по известной паре «шифр → буква» (кнопки ◄ ► или колесо мыши), затем сообщение читается и вводится с клавиатуры (3 попытки). |
| Настройка сигнала | На осциллографе нужно подогнать частоту, амплитуду (и фазу на высоких уровнях) под эталонную волну и удержать совпадение. |
| Маршрут | Протянуть пакет от входа к цели через сеть: обходить красные узлы защиты и (на высоких уровнях) заходить в ключевые узлы. Можно рисовать зажатой ЛКМ, ПКМ или BACKSPACE — шаг назад. |
| Взлом замка | Стрелка бежит по кругу, нужно нажать ПРОБЕЛ или ЛКМ, пока она в светящемся секторе. Каждый штифт ускоряет стрелку. |

| Сложность | Этапы |
|---|---|
| 1 низкая | 1 |
| 2 средняя | 2 |
| 3 высокая | 3 |
| 4 крайняя | 3 (самые трудные варианты игр) |

Интерфейс (`cl_ui.lua`): стеклянные панели с размытием фона, свечение текста, ЭЛТ-строки развёртки, анимированная «загрузка» соединения,
голограмма над узлом в мире. Сложность игр по уровням задаётся таблицами `({a, b, c, d})[level]` в `sv_games.lua`.

## Типы узлов и эффекты (длительность по сложностям 1/2/3/4)
| Тип | Модель по умолчанию | Эффект |
|---|---|---|
| `tablet` | props_lab/servers | Карта планшета у врага отключается: 4 / **10** / 15 / 20 мин (карта «НЕТ СИГНАЛА», метки и позиции не отдаются) |
| `radio` | props_lab/reciever_cart | Рации врага не работают (голос и /r, /ry, /rw): 2 / **5** / 8 / 10 мин |
| `archive` | props_silo/silo_server_d | Данные о солдатах врага. 1 — численность; 2 — + структура по званиям; 3 — + имена и звания; **4 (крайняя) — полное досье** (должность, онлайн, дата зачисления, взыскания/поощрения) |
| `cameras` | props_lab/securitybank | Контакты врага видны на экране, даже сквозь стены: 1 / 2 / 3 / 4 мин |
| `power` | props_c17/substation_transformer01a | У врага не включаются фонари: 1 / 3 / 5 / 7 мин |
| `finance` | props_c17/consolebox01a | Деньги переводятся взломщику: 50–100 / 100–200 / 200–350 / 350–600 |

Модель любого узла можно заменить: `/HackNodeSet model <путь>`.

## Команды администратора
- `/HackNodeAdd <тип> [сложность 1-4] [фракция|none]` — создать узел там, куда смотрите
- `/HackNodeSet <difficulty|type|faction|name|model> <значение>` — изменить узел под прицелом
- `/HackNodeRemove`, `/HackNodeList`
- `/HackResetCooldown <персонаж>` — сбросить откат
- `/HackClearEffects [фракция]` — снять все активные эффекты

## Настройки
Все значения в начале `sh_plugin.lua`: откат, паузы узлов, дистанции, классы, фракции, длительности (`HACK.types[...].durations`),
число этапов (`HACK.plans`), жизни (`HACK.lives`), оповещение при провале (`HACK.alertOnFail`).
Для проверки без класса: `HACK.adminBypass = true`.

## Состав файлов
`sh_plugin.lua` настройки и команды · `sv_hack.lua` сеансы, эффекты, интеграция с планшетом/рацией, сохранение узлов ·
`sv_games.lua` мини-игры (сервер: числа и проверка ответа) · `cl_games.lua` их интерфейс · `cl_ui.lua` общий стиль интерфейса · `cl_terminal.lua` окно терминала и досье ·
`cl_hack.lua` HUD, «нет сигнала» на карте планшета · `items/sh_hacktool.lua` · `entities/entities/ix_hacknode/`.

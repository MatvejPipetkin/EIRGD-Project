# ixnpcs — NPC System для Helix

Диалоги, задания, магазин и редактор. Устроен так же, как плагин vendor.

## Установка
Скопируйте папку `ixnpcs` в `plugins/` вашей схемы (или `helix/plugins/`) и перезапустите сервер.

## Использование
1. **Спавн:** Q-меню → вкладка *Entities* → категория *Helix* → *NPC (диалоги / квесты / магазин)*. Клик ставит NPC в точку прицела.
2. **Настройка:** зажать C → ПКМ по NPC → **Edit NPC** (пункт виден только superadmin).
3. **Удаление:** стандартное Q-меню / ПКМ → Remove.
4. Взаимодействие игроков — клавиша E.

NPC сохраняются на карте автоматически (при создании, правке, удалении, по таймеру Helix и при выключении сервера).

## Окно диалога
Кинематографичная камера на лице NPC, затемнение и «киношные» полосы, печать текста по буквам, варианты ответа с иконками (магазин, задание, сдача, выход), выбор мышью или клавишами 1–9, пробел — пропустить печать, Esc — закончить разговор.
Камеру можно отключить в консоли: `ix_npc_camera 0`.

## Окно торговли
Визуал перенесён из вашего cl_vendor.lua (сине-стальной HUD, две колонки «НА СКЛАДЕ» / «ВАШ ИНВЕНТАРЬ», карточка выбранного предмета, полоса запаса, анимированные фонды, звуки). Данные берутся из магазина NPC. У NPC бесконечные средства; остаток и вместимость склада работают как «Остаток» в редакторе. Акцентный цвет окна — цвет NPC (по умолчанию синий).

## Редактор (C → ПКМ по NPC → Edit NPC)
Визуальный, без JSON: вкладки «Основное» (имя, модель с 3D-предпросмотром, скин, цвет диалога), «Диалоги» (узлы, варианты, условия, действия), «Задания» (цели, награды, повтор), «Магазин» (таблица цен и остатков). Кнопка «Предпросмотр» показывает диалог так, как его увидит игрок. «Экспорт/Импорт» копируют конфиг через буфер обмена.

## Команды
| Команда | Кто | Что делает |
|---|---|---|
| /NPCList | superadmin | список NPC на карте |
| /QuestLog | все | активные задания игрока |

## Права и безопасность
- CAMI-привилегия `Helix - Manage NPC System` (MinAccess = superadmin) плюс жёсткая проверка `IsSuperAdmin()`.
- Проверка на сервере при спавне, открытии редактора и каждом сохранении.
- Physgun/Toolgun/Properties на NPC — только superadmin.
- Произвольный Lua в конфигах не исполняется: белый список действий, весь ввод проходит Sanitize.
- Клиент получает только текст текущего узла и доступные ему варианты, а не всё дерево.

## Формат конфигов
Редактировать вручную больше не нужно; при желании конфиг можно экспортировать кнопкой «Экспорт» (JSON).

# Durability / Починка

Прочность и починка оружия **и брони**.

## Что чинит какой комплект

В файле ремкомплекта включается один из флагов:

```lua
ITEM.isWeaponKit = true   -- только оружие (по умолчанию)
ITEM.isArmorKit = false   -- только броня
```

Готовые комплекты: `items/repair_kit/sh_armor_kit_1..3.lua` (броня) и `sh_hobo_kit_1..3.lua` (оружие).
Комплект для оружия броню не чинит, и наоборот.

## Выбор комплекта

Пункт «Починить» в меню предмета открывает подменю со всеми подходящими комплектами игрока
(одинаковые комплекты не дублируются — предлагается самый начатый). В строке видно название, остаток использований и % восстановления.

## Параметры комплекта

```lua
ITEM.repairPercent = 20 -- сколько % от максимальной прочности восстанавливает за использование
ITEM.uses = 5           -- сколько использований в комплекте
```

| Тир        | % за раз | Использований | Всего   |
|------------|----------|---------------|---------|
| Кустарный  | 10       | 2             | 20%     |
| Базовый    | 20       | 5             | 100%    |
| Улучшенный | 30       | 8             | 240%    |

Счётчик использований хранится в `uses` (раньше `quantity` — из-за совпадения с полем Helix цифра на иконке рисовалась дважды).
Старые предметы читаются и переносятся на новый счётчик при первом использовании.

## Броня

Нужен плагин `armorweight`: он считает износ, показывает состояние и защиту с учётом износа.
Максимум прочности брони задаётся в её файле: `ITEM.armorStats.durability`.
Любой предмет с характеристиками armorweight (в том числе одежда Simple Inventory Slots) получает пункт «Починить»
автоматически, дописывать ничего не нужно.

# Захват точек (Helix)

Точки на карте, за которые бьются фракции. Владельцы и ход захвата видны на карте служебного планшета.

## Установка
1. Папку `capturepoints/` положить в `plugins/` схемы.
2. Файл `tablet_patch/derma/cl_tabletmap.lua` заменить в `plugins/tablet/derma/` (или внести 3 вставки из `cl_tabletmap.patch`: в карту добавлены хуки `TabletMapThink`, `TabletMapPaint`, `TabletMapTooltip`). Больше в планшете ничего менять не нужно.
3. Перезапустить сервер.

## Как работает захват
- Точка — цилиндр: радиус и допустимая разница по высоте (±) от центра.
- Считаются живые бойцы фракций-участников (по умолчанию — фракции из `ix.tablet.factions`), не в noclip.
- Одна фракция в зоне — набирает прогресс. Один боец захватывает за `captureTime` секунд (90),
  каждый следующий добавляет +50% скорости, максимум ×3.
- Две и больше фракций в зоне — спор, прогресс замирает (на карте жёлтое пульсирующее кольцо).
- Владелец в зоне сбивает прогресс захватчика. Если зона пуста, прогресс сам сходит на 0 за `restoreTime` секунд.
- При захвате фракции получают уведомление; владелец получает предупреждение, когда точку атакуют.
- Владельцы сохраняются между рестартами (отдельно для каждой карты). Прогресс захвата — нет.

## Команды (только админы)
| Команда | Что делает |
|---|---|
| `/CapPointAdd <название>` | создать точку там, где вы стоите |
| `/CapPointRemove <номер>` | удалить точку |
| `/CapPointMove <номер>` | перенести точку в вашу позицию |
| `/CapPointRadius <номер> <радиус> [высота]` | размер зоны |
| `/CapPointOwner <номер> <фракция\|none>` | назначить владельца вручную (uniqueID или часть названия) |
| `/CapPointList` | список точек, владельцы, прогресс |

Консольная команда `ix_capture_zones 1` (админам) рисует зоны точек в мире — удобно подбирать радиус.

## Настройки
Настройки лежат в конфиге сервера Helix: **F1 → Конфиг → категория «Захват точек»** (нужны права на изменение конфига).
Менять можно прямо на запущенном сервере, без правки файлов и рестарта: список фракций (uniqueID через запятую, пусто —
фракции планшета), радиус и высота по умолчанию, время захвата, бонус за бойцов, скорость отката, лимит точек и т.д.
Определения настроек и значения по умолчанию — в начале `sh_plugin.lua`.

## Хук для наград и логов
```lua
function PLUGIN:CapturePointCaptured(point, newFactionID, oldFactionID)
	-- point.id, point.name, point.x/y/z; oldFactionID может быть nil (точка была нейтральной)
end
```
Список точек из другого кода: `ix.capture.GetPoints()`.

## На карте планшета
- Значок точки цвета владельца (серый — нейтральная), подпись с названием, полупрозрачная зона по реальному радиусу.
- Дуга вокруг значка — прогресс захвата в цвете захватчика, рядом проценты.
- Наведение мыши — владелец, сколько удерживается, кто и насколько захватил.
- Кнопка «Точки» справа под компасом включает и выключает слой.
- Данные запрашиваются только при открытом и авторизованном планшете (раз в секунду).
